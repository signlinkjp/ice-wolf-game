# ICE WOLF v1.2.0 Build 34 — 実機の録画に答えるビルド

Build 33 を実機で録った動画の3点と、あとから届いた1つの要望に、出荷する
GDevelop プロジェクトの中で答えました。バージョンは `1.2.0` のまま、
`CURRENT_PROJECT_VERSION` だけが **34** です。

## 1. 「救助も出来なくなってます」（直接タッチ操作）

**原因**：Build 33 の直接タッチ（画面のどこを触っても移動）は、キャンバスの
上に画面いっぱいの `<div>` を置き、その `pointerdown` でスティックを出して
いました。GDevelop が描いている `[ 救助 ]` などのボタンはその下なので、
指はボタンに届かず、ボタンは光るだけで何も起きませんでした。

**対処**（`v1.2.0 表示・操作設定`）：

- `<div>` は**飾りだけ**（`pointer-events: none`）。何も塞ぎません。
- ジェスチャーは **window の capture 段階**で読み、**ゲームのキャンバスに
  降りた指だけ**を対象にします。DOM のボタン（MENU / CAM / 各シート）は
  まったく触りません。
- 指が HUD のボタンの上かどうかを、**GDevelop 自身が使うのと同じカメラ変換
  （`convertInverseCoords`）**で毎フレーム判定し、当たっていれば**移動に
  しない**でゲームにそのまま渡します → ボタンの `IsPressed` がそのまま動く。
- それ以外は今までどおり：指の下にリングが出て、ドラッグのベクトルが
  これまでのスティックと同じ変数（`JoystickX` / `JoystickY`）に書かれます。
- 何回ボタンに譲ったかを `PlayerHudTapGuard` に出します（検証用）。

対象は `RescueButton` / `WolfButton` / `InfectButton` と、デバッグ用の
3ボタン、D-pad 8方向 — ButtonFSM を持つ＝指で押す対象すべてです。

## 2. 「キャラが走り回らない」

（`v0.7.3 ブロックトイ3Dキャラ`）

- 体を **112 → 122**、少し横に広く（×0.66 → ×0.68）。
- 4コマの切り替えを **9 → 18 px 歩行ごと**に。9 だとジョグの速度で毎秒4サイクル
  回ってしまい、目には**ブレた縞**として映ります（＝「写真が滑っている」）。
  18 は秒に1.5ストライドほどで、**1コマがちゃんと見える速さ**。その間を
  バウンスと伸縮が刻みます。
- ストライドの上下を 6.5 → **10.5** に。
- **スクワッシュ＆ストレッチ**：足が離れる瞬間に縦 +7%、着地で横 +5.5%。
  1枚絵のスライドには絶対に出ない「走りの伸び縮み」です。
- 前傾 0.13 → **0.17**、足元の雪は粒を大きく（15 → 19）。
- カメラを寄せて（下記）**画面上のキャラをさらに大きく**。

## 3. 「ステージクオリティ落ちてます」

- **ライトを落としました**。Build 33 はシーン既定の2灯に加えてほぼ2灯分を
  足していて（合計約2.8）、どのテクスチャも白飛びしていました。Build 34 は
  「色の照り返し（hemisphere）＋形を出すキー＋後ろからのリム」の3灯で
  合計 1.5 前後。**壁のレンガ、雪、床がそれぞれの色を保ちます。**
- **すべての壁に雪のキャップ**：壁の footprint ちょうどの雪の板（上 14px、
  テクスチャ＋上下で焼き分けた頂点色）を**ステージごとに1メッシュ**へ結合。
  上から見たときの「上面の雪・14px の側面・その下の影」で、壁が**ブロック**
  として読めます。色は焼き込みなので、端末のライトがどう転んでも同じです。
  （テクスチャ側に「縁」は描きません。1520px の外周壁では 160px ごとに
  縁が並び、壁がトレイの列に見えてしまうためです。）
- **ステージに天気**：1つの Points メッシュで、氷の雪・水槽の泡・
  遊園地の花びら・ロッジの火の粉・廃校の塵・宇宙の星。粒は生きている間だけ
  書き込みます（1ドローコール）。
- **クラシックの3枚を描き直し**（`tools/b34/make_classic_textures.py`）：
  壁＝深い氷のレンガ＋各段の雪、天面＝氷のブロックの縁と吹き溜まり、
  床＝より深い氷にシャープなスケート跡とひび。**タイル状に並べても帯が
  出ないよう、線形グラデーションは使わず回り込む波だけで描いています。**

## 4. 「ゲームプレイ画面内の状況説明も、見やすくポップに」

新グループ **`v1.2.0 ポップHUD`**（シートの最後）：

- これまでの HUD 文言（`RoleText` / `CountText` / `SwitchText` / `GateText` /
  `FloorText` / `TimerText` / `StatusText` / `ActionFeedbackText` / `WinText`）を
  **同じ文字のまま**、角丸チップ・大きなタイマー・下部のヒントバー・
  中央のトースト・勝者バナーとして描き直します。
- 文字は**イベントシートが書いたその文字**（＝12言語の翻訳も文字サイズ設定も
  そのまま効く）。読み終えた後にだけ、元のテキストを透明にします。
- 色は役割（人間＝金／人狼＝赤／凍結＝氷）・ゲート開放（緑）・残り30秒
  （赤く脈打つ）で変わります。
- 救助ボタンの下には**緑のピル**を敷いて、押せるボタンとして見えるように。
- はみ出し対策：チップ列は最大 58vw、ヒントバーは `min(74vw, 760px)`、
  セーフエリアを避け、`--s`（標準/大/特大）で全体を拡大縮小。
- 何かの理由で DOM の HUD を出せない端末では、元のテキストを**そのまま**
  残します（二重表示もしません）。

## カメラ

`470 / 50°`（通常）、`900 / 73°`（俯瞰）、観戦 `540 / 50°`・`960 / 73°`、
凍結中の俯瞰 `1350 / 82°`。Build 33 が Layer パラメータに残していた `58` も
掃除しました（既定レイヤにコンパイルされていて効果がありませんでした）。
