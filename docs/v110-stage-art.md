# ICE WOLF v1.1.0 — 5ステージの本格ビジュアル（テクスチャ・3D小道具・空気）

Build 16 の深海水族館は「FROST LAB に青い色を掛けただけ」に見えました。PRO 500円の
価値は「別の場所で遊べること」なので、v1.1.0 の5ステージは**それぞれが自分の
壁・天端・床のテクスチャ**と**自分の3D小道具**と**自分の空気（フォグ・空の色）**を
持ちます。クラシック（FROST LAB）は 1.0.0 のままです。

## 2. 仕組み（`v1.1.0 ステージ・衣装` の2つ目のイベント）

1. ステージが変わった瞬間だけ動きます（毎フレームの処理はゼロ）。
2. `Wall` の前・後・左・右の面に `wall_<stage>.png`、上・下の面に `cap_<stage>.png` を
   `setFaceResourceName` で貼り、`setTileScale(0.3125)` で、高さ160pxの壁面にちょうど1模様（512pxのテクスチャ1枚ぶん）が収まるようにします。
   `Floor` は6面とも `floor_<stage>.png`、`setTileScale(0.5)`。
3. 壁の上（z = 壁の高さ）に小道具を置きます。**床には何も置かない**ので、小道具が
   プレイヤーの進路を塞ぐことはありません。
   - 外周の8枚の壁：`border` キットを長さに沿って等間隔（2〜4個）
   - 内側の壁：そのステージが使う寸法だけ（例：90×90 の柱→水槽柱、320×32→暖炉）
   - 12枚の待避中の壁（y = 40000）は触りません
4. 小道具は**素材ごとに1メッシュへ合成**します（不透明＋発光の2メッシュ＝2ドロー
   コール）。頂点は数千規模で、iPhone では無視できる負荷です。
5. `THREE.Fog` と `setBackgroundColor` で空気を入れ替えます。
6. クラシックへ戻すときは、フロストラボのテクスチャ・タイル倍率・空気を元に戻します。

### 上下が入れ替わっても大丈夫なように

GDevelop の Cube3D は、壁の2つの広い面のうち片方でテクスチャの v が反転します
（`Cube3DRuntimeObjectPixiRenderer.updateTextureUvMapping`）。どちらが反転するかは
エンジン側の都合で決まり、実機で確かめるまで分かりません。そこで壁のテクスチャは
**中央線で上下対称**に描いてあります（砂と珊瑚は上下の両端、幕と電球も両端、
腰壁は上下、黒板と窓は中央）。どちら向きに貼られても「逆さまだ」と分かる絵に
ならないので、見た目が壊れません。

## 3. テクスチャの生成

    python3 tools/make_stage_textures.py

`assets/` に 15枚（5ステージ × 壁/天端/床、各 512×512）を書き出します。
すべて継ぎ目なくタイルし、256色に量子化してあります（合計 ≒ 550KB）。
乱数の種は固定なので、何度実行しても同じバイト列になります。
水面のコースティクスと雪の風紋は、整数周波数の sin の和なので、タイルの端で
必ずつながります。

## 4. SETTINGS のカメラ行

`Default camera` が日本語UIで英語のままだった件を直しました（12言語すべて）。

| --- | --- | --- |
| `settings.camera` | 既定カメラ | Default camera |
| `settings.movement` | 移動 | Movement |
| `settings.movementValue` | コンパクト仮想スティック | Compact virtual joystick |
| `joystick.aria` | 移動スティック | Movement joystick |
| `camera.aria` | 俯瞰カメラの切り替え | Toggle overview camera |

## 5. 触っていないもの

移動速度・当たり判定・凍結/救助・スイッチ/ゲート・階段・ワープ・スピード床・AI・
カメラの距離は 1.0.0 の数字のままです。壁は**動かすだけで、サイズもテクスチャの
当たり判定も変えません**。`tests/pro/scope-guard.test.mjs` が 1.0.0 のアセット・
イベント順・数値を毎回突き合わせます。
