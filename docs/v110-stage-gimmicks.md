# ICE WOLF v1.1.0 Build 19 — 5ステージ固有ギミックと試合時間チップの修正

Build 18 の実機確認で、トモアキさんから2つ届きました。

1. **PRO で「1分」「10分」を選ぶと、3分・5分と同時に選択状態になって遊べない**
2. **ステージごとに遊びの個性（ギミック・演出）が足りない** — ボンバーマン式に、
   ステージごとの専用ルールが欲しい

Build 19 はこの2つに答えます。クラシック（1.0.0）は無傷のままです。

## 1. 試合時間チップの同時選択バグ

### 原因

Build 18 は「1分・10分」を後のブロック（`v1.1.0 人数・2人狼・ルール`）で
`time60` / `time600` の2つのチップとして追加し、既存の2/3/5分チップ
（`v0.6.5 Production Round Start + Main Menu` の設定画面）とは**別々に**点灯状態を
書いていました。

- 設定画面の `updateSettingsUi` は `time120/180/300` しか点灯・消灯しない
- 追加チップ側は `time60/600` だけを点灯する
- そのため「3分が点灯したまま1分を押す」と **2つが同時に点灯** した
- さらに保存値の復元は `120/180/300` しか受け付けず、**1分・10分は再起動で消えていた**

### 修正

- 5つのチップの答えを **1つの関数** `iceWolfDurationChipOn(duration)` にまとめ、
  `runtimeScene.__iceWolfV110DurationChip` として公開
- 設定画面の `updateSettingsUi` が `time60 / 120 / 180 / 300 / 600` の**5つすべて**を
  同じ1つの値から点灯（同時に2つは点灯しない）
- 追加チップ側（`refreshRows`）も**毎フレーム**5つ全部を点灯し直し、注記
  （「試合時間: n分」）も同じ値から書く
- 1分・10分を押した瞬間に `refreshRows()` と `updateSettingsUi()` の両方を呼ぶ
- 保存値の復元が `60 / 120 / 180 / 300 / 600` を受け付ける
- チップの並びを **1 / 2 / 3 / 5 / 10 分** に整列
- 反映は既存どおり `DurationPreference` → `MatchDuration` → ラウンド開始時の
  `MatchTimeLeft`（`resetRound`）で、押した秒数がそのまま試合時間になる

テスト：`tests/pro/v111-gimmicks.test.mjs`

- 5つの時間それぞれで「点灯するチップはちょうど1つ」
- 未知の値（0 / 210 / 999）では何も点灯しない
- 設定画面と追加チップが同じ関数から点灯していること（ソース検証）
- 60 / 600 が `iceWolfMatchSeconds` を通り、`MatchDuration` に入ること
- 保存値の復元が 60 / 600 を受け付けること

## 2. ステージ固有ギミック（`v1.1.0 ステージ固有ギミック`）

タイマー付きの演出は**試合時計**（`MatchDuration - MatchTimeLeft`）から読みます。
`MatchTimeLeft` は通信対戦でホストが全端末へ配っている値なので、**マンタ・吹雪・停電・
警報は全員の端末で同じ秒に起きます**。演出は見た目だけで、当たり判定・タイマー・
ルールには触れません。

| ステージ | 常時 | 一定テンポ（試合時計） |
| --- | --- | --- |
| 🐠 深海水族館 | **海流レーン**（1Fは+x・2Fは−xへ54px/s、矢印＋泡）、渦潮ワープ、泡リフト階段 | **巨大マンタ**が27秒ごと・3秒間、両フロアの上空を横切る |
| 🎡 霧の遊園地 | 壁の電球列が明滅、**床の回転スポットライト2基/フロア**、スピード床のコースター加速演出 | 16秒ごと・6秒間、**紙吹雪**＋スポットライトが速く回る |
| 🏔️ 雪山ロッジ | **氷床**（北側の通路が滑る） | 29秒ごと・5秒間、**吹雪タイム**（霧が240〜1150へ寄る＋雪） |
| 🏫 廃校 | — | 24秒ごと・4秒間、**停電タイム**（画面が暗くなる） |
| 🚀 宇宙船 | **低重力ゾーン**（南側の帯で移動+18%）、船体の警報ランプ | 21秒ごと・3秒間、**警報**（赤い明滅） |

クラシックは `ICE_WOLF_GIMMICK_ZONES` / `ICE_WOLF_GIMMICK_CYCLES` に項目がなく、
メッシュも出ません（1.0.0 のまま）。

### 公平性と通信対戦

- 拍は `MatchDuration − MatchTimeLeft`。通信対戦では試合時間も**ホストの開始payload**
  （`OnlineStartSeconds`）から取るので、ゲストが時間を選んでいなくてもホストと同じ拍になります。
- ゾーンは**マップ上の固定矩形**（1F/2Fは既存の `x > 792` の分割）。全端末で同じ。
- 効果は**ローカルの Player** と、**オフラインまたはホストが動かしている CPU** にだけ
  適用します。ゲストはスナップショットが所有する席（`__iceWolfV110Remote`）を動かさず、
  CPU AI も走らせません。位置の作者が1人だけなので、押し合いになりません。
- 押し出しは毎フレーム、**既存の壁矩形**（`__iceWolfV074Rects`、壁+7px）と
  フロア端（1F: −699.5〜700.5 / 2F: 900.5〜2300.5、y ±699.5）で判定し、
  入れない位置なら軸ごとに分けて試し、それでも駄目なら動かしません。**壁の中に入ることはありません。**
- 速度・当たり判定・スイッチ・ゲート・救助・階段・ワープの数値は 1.0.0 のまま。
- このブロックは `v1.1.0 オンライン対戦同期` の**直前**に置き、同期ブロックは最後のまま
  （スナップショットは「ゾーンを適用した後の位置」を配ります）。

### 動きの作り

- **海流**：ゾーン内で毎フレーム `power × dt` を押す（1F:+x / 2F:−x）。
- **氷床**：直前フレームの入力と、ゾーンが足した分の減衰（×0.74/フレーム）を
  足して滑らせます。入力が止まっても0.2〜0.3秒ほど滑り、上限5.2px/フレーム。
- **低重力**：そのフレームの入力の18%を足す。
- ワープ・階段・復帰のような1フレーム90px超の移動は「入力」と見なさず、滑りをリセット。

## 6. Build 20 — 遊園地の演出を入れ替え（HUDを覆わない）

Build 19 の遊園地は、画面の**上端と下端15%**にピンク／シアン／橙の縦縞カーテン
（`iwfx-park:before/after` の `repeating-linear-gradient`）を被せていました。そこは
`あなた：人間`・`生存`・`スイッチ`・`ゲート` とタイマーがある場所で、HUDが読めなく
なっていました（トモアキさんの指摘）。Build 20 で入れ替えました。

* **縦縞カーテンは廃止。** `iwfx-park` は画面全体に敷いたままですが、
  `mask-image` で**上16%〜34%を透明**にし、HUDの帯には一切描きません。
* **回転サーチライト**：`conic-gradient` の24pxの円を `scale(84)` で拡大し、26秒で
  1回転。小さいレイヤをGPUで回すので、端末が画面サイズのグラデーションを
  ラスタライズしません（メモリ対策）。
* **紙吹雪**：拍の6秒間だけ、画面中段に6色の粒を降らせます（HUDの帯はマスクで除外）。
* **3Dの光の輪**：`iceWolfV111Pool` を各フロア2基、床に寝かせて回転。拍の間は
  明るさが上がります。当たり判定なし・半透明・`depthWrite:false`。
* **観覧車と風船**はステージ・衣装ブロックの小道具（壁の上だけ）。
* 12言語の文言も更新：`fx.park.lights`（カーニバルの光が回り出す！）と
  `stage.park.gimmick`（回るスポットライト・紙吹雪・コースター加速）。

テスト（`tests/pro/v111-gimmicks.test.mjs`）：
* `iwfx-park` に縦縞カーテンがなく、上端に何も置かないこと（正規表現でソース検証）
* マスクが上16%を透明にしていること
* 光の輪が4基、床に寝ていて、回転し、拍で明るくなること

## 7. Build 21 — 廃校の密室・宇宙船の高重力・5分上限・スイッチ10個

Build 20 の実機確認で、トモアキさんから4点届きました。ゲームの骨格（移動・当たり
判定・カメラ・救助・階段・ワープ・1.0.0 の数値）は触っていません。

### 7.1 🏫 廃校：停電をやめて「チャイム → 教室ドア5秒閉鎖」

* **停電（画面が暗くなる演出）は撤去。** 視覚を奪うだけだったので、遊びの中身に
  変えました。
* 試合時計の**拍（period 26秒・offset 6秒）**で、まず **チャイム2.5秒**（音＋暖色の
  縁、`fx.school.chime`）。
* 続く **5秒間**、そのフロアの**教室エリアの境界（ドア）が閉まり**、**中からも外からも
  通れません**（`fx.school.doors`、`StageGimmickDoor = 'shut'`）。
* **5秒後に必ず自動で開きます。** 教室の中のスイッチやゲートが永久に取れなくなる
  詰みはありません（1周のうち閉まっているのは5秒だけ）。
* 閉まる側は「閉まった瞬間にいた側」で決まります。中の人は出られず、外の人は入れ
  ません。当たり判定は毎フレーム、**そのフロアの壁判定と同じ**矩形で確認し、壁の中
  には入りません。
* 教室エリアはマップの教室ブロックそのもの（1F: x −398〜430 / y −108〜110、
  2F: x 1132〜1990 / y −618〜150）。**全端末で同じ部屋**です。
* 見た目：ドア2枚（`iceWolfV111Door`）と教室を囲む線（`iceWolfV111Seal`）。閉まって
  いる間は緑、チャイム中は暖色で明滅。試合中以外は消えます。

### 7.2 🚀 宇宙船：赤い点滅をやめて「高重力マス」

* **画面全体を赤くする非常灯は撤去。** 予告は2.5秒の**控えめな琥珀の縁**だけ
  （`fx.space.alarm`）。船体のランプも赤ではなく琥珀で、警告中に灯ります。
* 予告のあと **10秒間**、両フロアに**6個の高重力マス**（`fx.space.gravity`）が
  出ます。紫〜青のリング＋四隅の印で、床の上でも一目で分かります。
* マスの上にいるキャラ（人間・人狼・CPU）は**移動速度55%**。1フレームの移動の45%を
  壁判定つきで戻すので、速さは毎フレーム正確に55%です（氷の滑りのように増幅しません）。
* **位置はシード同期**：ルームの開始シード（`OnlineStartSeed`）から決定的に6個を
  引きます。オフラインは1試合ごとに新しいシード。**全端末で同じ6個**が同じ秒に
  出て、同じ秒に消えます。
* マスは**壁の上に出ません**（壁矩形と6px以上あけて抽選）。マス同士も重なりません。
* 宇宙船の**低重力ゾーン（南側の帯）はそのまま**（船の常設ルール）。高重力マスの上
  では高重力が優先されます。

### 7.3 試合時間は最長5分

* SETTINGS の制限時間から **10分を削除**。**1分 / 2分 / 3分 / 5分**の4択です
  （PRO/無料とも10分はありません。1分はこれまでどおり PRO）。
* 保存済み設定に10分が残っていた場合は **5分にフォールバック**し、保存値も
  5分に書き直します（次の起動で戻りません）。通信対戦のルールでも同じです。

### 7.4 スイッチは3 / 5 / 7 / 10個、正解は3 / 5個

* 合計：**3個 / 5個 / 7個 / 10個**（初期5個。5個以外は PRO、通信対戦はホストの設定）。
* 正解：**3個 / 5個**（初期3個。5個は PRO）。SETTINGS に「正解スイッチ」の行を追加。
* **整合性ガード**：合計3個のときは正解5個を選べません（チップが無効化され、保存値も
  3個に切り詰め）。合計を3個に変えた瞬間に、正解が5個なら3個へ戻ります。
* マップの**スイッチ候補は13箇所**（従来10＋3）。10個引いても全ステージの壁に
  重ならず、**ゲート3個がすべてスイッチから150px以上**離れた場所に置けます
  （`tests/pro/v111-rules.test.mjs` が全ステージ・全組み合わせで検証）。
* `SwitchPad` の実体を**5枚→10枚**に増やしました（オブジェクトは1つのまま）。
* HUD は **`スイッチ: X/Y`**（Yは今回の正解数）、`スイッチ起動！（X/Y）`、ゲート開放は
  **最後の正解スイッチ**で発動。12言語の `hud.switch` / `fb.switchOn` も `{n}/{t}` に。
* 通信対戦：ルームが**合計と正解の両方**を持ち、開始payloadで全員に配ります
  （`OnlineStartSwitches` / `OnlineStartCorrect`、スナップショットは最大10個）。
