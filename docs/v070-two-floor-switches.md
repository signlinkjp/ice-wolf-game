# ICE WOLF v0.7.0 — 2階・階段・5スイッチ・3ゲート

v0.7.0 は「かくれんぼの迷路」だった1Fに、もう1枚のフロアと脱出の目的を足した回です。
1Fの当たり判定・壁・カメラ・既存ギミックは一切変えず、追加分だけで動くようにしています。

## 1. 2Fフロア（1Fと重ならない別エリア）

- 座標は **XY平面上で +1600px 横にずらした別エリア**（1F: x −708〜692 / 2F: x 892〜2292、Yは共通で −708〜692）。
  2つのフロアは決して重ならないので、壁の当たり判定・カメラ遮蔽・救出距離の判定が混ざりません。
- 2Fは専用の床スラブ（x 906〜2346）と **14枚の壁**（外周4・中央の閉じたリング4・横バー2・柱4）を持ち、
  リングのまわりを一周する周回ルートになります。
- 床は暖色（アンバー）、2Fの壁はオレンジ寄りに色付けし、1Fの寒色と一目で区別できます（同一オブジェクトを
  インスタンス単位で着色するので、壁の分離・視線判定・CPU回避のロジックは1Fと共通のままです）。
- 境界クランプは「プレイヤー中心のXが792以下なら1F、超えたら2F」で床ごとに判定します。
  2つのフロアの間（692〜892）は歩けない隙間です。
- HUDの `FloorText` が現在の階（1F / 2F）を表示します。

## 2. 階段ワープ（2か所・クールダウン付き）

- 階段パッドは4枚（1F-A / 1F-B / 2F-A / 2F-B）。**0↔2、1↔3** が対で、+1600px の移動になります。
- プレイヤー・人間CPU・人狼CPUのすべてが乗ると移動します。クールダウンは2.4秒で、乗りっぱなしでも往復しません。
- 既存の紫のワープパッド（`WarpPad`）とは別オブジェクト・別ラベル（🪜 1F→2F / 2F→1F）で、混同しません。
- CPUは行きたい相手・スイッチが別フロアにいるとき、自分で階段へ向かいます（人狼の追跡・人間の救助・
  スイッチ工作のすべてに階段ルートを組み込み済み）。

## 3. 5スイッチ（毎試合ランダム）

- 候補は**安全な床10か所**（1F 6・2F 4）。毎試合シャッフルして**5か所**に配置します。
- 内訳は人数で自動的に変わります。

  | 試合の人数 | 正解 | ダミー | 罠 |
  | --- | --- | --- | --- |
  | 7人以下（現在の6人戦を含む） | 3 | 2 | 0 |
  | 8人以上 / SETTINGSで「常にON」 | 3 | 1 | 1 |

- 起動は**長押し1.6秒**。v0.6.9の円形ゲージを踏襲した専用リング（画面下中央）が一周すると起動します。
  指を離す・スイッチから離れるとゲージは0に戻り、途中離脱しても壊れません。
- 起動できるのは**生存中の人間だけ**です（人狼が押しても何も起きません）。
- ダミー: ハズレ表示と音だけで、進捗は増えません。
- 罠: 押した人間が**その場で3人目の人狼**になり、赤耳（人狼モード5秒）に変身して全体に通知されます。
- 人間CPUも、逃走も救助もないときに近くの未起動スイッチへ向かって同じ手順で起動します。

## 4. 3ゲート（毎試合ランダム・正解3つで1つだけ開放）

- 候補10か所から、スイッチと重ならないように**3か所**を毎試合選び、**試合開始時から 🔒 閉鎖ゲートとして表示**します
  （どのゲートが開くか分からないので、ゲート前キャンプが成立しません）。
- 正解スイッチが3つ起動した瞬間、3つのうち**ランダムで1つだけ**が 🟢 OPEN!! と緑に光り、
  効果音・画面通知・「開放された階（1F / 2F）」の表示が出ます。残り2つは赤いまま消灯します。
- 開放されたゲートに**生存中の人間**（プレイヤーまたは人間CPU）が触れると、その場で**人間の勝利**。
  人狼が触れても何も起きません。

## 5. 設定（SETTINGS）

- `スイッチ脱出` **ON / OFF**（デフォルト ON）。OFFにするとスイッチ・ゲート・HUDが消え、CPUも工作しません。
- `罠スイッチ` **人数連動（8人〜） / 常にON / OFF**（デフォルトは人数連動）。
  人数連動では7人以下の試合でダミー×2、8人以上でダミー×1＋罠×1になります。
  現在の人数と有効/無効は設定画面の注記にそのまま出ます。
- 既存の設定（役割・試合時間・サウンド・カメラ）はそのまま維持しています。

  （ラベルと役割そのものは変更なし）。`[ 人狼モード ]` 側は変更していません。
