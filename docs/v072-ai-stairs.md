# ICE WOLF v0.7.2 — AI人狼とAIヒューマンの1F⇄2F階段移動

v0.7.2 は「2階にコンピュータ達（人狼・ヒューマン）が行き来しない」というトモアキさんの指摘に、
**AI専用の階段ルール**を足して応えた回です。プレイヤーの操作感・当たり判定・マップ・
スイッチ／ゲート・カメラ・音・既存AIの追跡／逃走／救助の速度は変えていません。

## 1. まず見つかった根本原因（v0.7.0の階段ルートのバグ）

v0.7.0 の `__iceWolfV070StairToward` は「行きたい相手の階のパッド」を選んでいました。

```js
const wantFirstFloor = toFloor === '1F';   // ← 目的地の階
if (onFirstFloor !== wantFirstFloor) continue;
```

1Fから2Fの相手を追う人狼は **2F側のパッド** に向かって歩き、床の切れ目（x 692〜892）で
クランプされて壁沿いを滑るだけでした。同じ関数を使う人間のスイッチ渡りも同じ理由で
成立していませんでした。v0.7.2 で **自分の階のパッド** を選ぶよう修正しています
（どのパッドも必ず反対の階へ渡るので、これが正しい）。

```js
// v0.7.2: pick the pad on the rider's OWN floor.
const wantFirstFloor = fromFloor === '1F';
```

これが「AIが階段で行き来しない」の実体で、以下のルールはこの修正の上に載っています。

## 2. AI共通の階段ワープ＋クールダウン

- ワープ先はプレイヤーと完全に同じ（`StairPad` 4枚、0↔2 / 1↔3、+1600px）。
  AIはパッドの中心へ歩き、**接触した時点**でプレイヤーと同じ処理で移動します。
- **プレイヤーは従来どおり2.4秒**（操作感を変えない）。
- **AIは個体ごとに4.0〜5.0秒**（乗るたびにその範囲で抽選）。7人全員が同じテンポで動かないよう
  個体差を持たせています。値は `AiStairCooldownMin` / `AiStairCooldownMax` で公開。
- **着地の76pxステップオフ**：AIは着地後、部屋の中央方向へ76pxずらして降ります
  （壁に重なる場合は上下へ退避）。パッドの上に立ち続けてクールダウン明けに即再乗車する
  「ピンポン」を構造的に潰すためです。プレイヤーの着地位置は従来どおり。
- **階ロック**：乗った直後は 人狼7.0秒 / 人間3.0秒、その階で狩り・工作を続けます。
  クールダウンだけでなく「判断」の往復も防ぎます。

## 3. AI人狼の階移動判断

1. **同じ階に追える生存ヒューマンがいれば、その階で狩る**（従来の追跡・潜伏・WOLF MODE）。
   別の階のヒューマンは「階段に乗る理由」にだけ使い、境界の壁沿いを滑らせません。
2. 同じ階に獲物がいない状態が **1.6秒**続くと、**最寄りの階段へ移動**して別階へ渡ります
   （移動速度150px/s。巡回なので全力疾走はしない）。
3. 渡った後は **7秒間その階をロック**：到着直後は4秒間、階の中央方向へパトロールし、
   その階のヒューマンを見つければそのまま追跡に移ります。ロック中は例え獲物が別階に
   見えても渡りません（＝行き来のピンポン防止）。
4. ロックが明けて、その階に獲物がいなければ再度階段へ。この繰り返しで両階を巡回します。

## 4. AIヒューマンの階移動判断

1. **逃走**：同じ階に WOLF MODE の人狼がいて **300px以内**、かつ乗車ゲートを通れば
   **階段を逃走経路にする**（走る向きは「近いが人狼から遠いパッド」をスコアで選択）。
   一度選んだパッドは、乗る・6秒経過・ラウンド終了まで歩き続けます（毎フレーム迷わない）。
2. **スイッチ工作**：同じ階のライブスイッチを優先。**同じ階に未押下スイッチがない**場合は
   別階のスイッチへ階段で渡ります（v0.7.0のスイッチ意図に「行き先の階」を持たせ、
   v0.7.2側で乗車を許可制にしました）。凍結者の救助が別階にいる場合も階段を使います。
3. **救助**：凍結者が**別の階**にいる場合（探索520px内）も階段で渡ります（従来は境界の壁に向かって
   歩くだけでした）。到着後は従来どおり近づいて解凍します。
4. **分散（溜まり防止）**：
   - 乗車開始まで **0.5〜1.8秒の個体別ディレイ**。
   - 同時に階段へ向かえる人間は **2人まで**（`AiStairBoundLimit`）。3人目以降はその場で
     逃走・救助・巡回を続け、枠が空いてから渡ります。
   - 乗車・6秒タイムアウト・ラウンド終了で枠は解放。
