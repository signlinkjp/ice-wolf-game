# ICE WOLF v1.0.0 Build 8 — マップのギミックを整理してひと回り小さく

Build 7 の実機プレイ動画（`ScreenRecording_11-17-2026 07-04-46`）で トモアキさん が
指摘した2点への対応です。

> 「ワープと2階への階段の位置が近過ぎて、あの辺ゴチャついて動きづらいです‼︎」
> 「各アトラクション的なやつ(ワープ、階段、スピードアップ、脱出ゲート、ボタン)は
> もう少しだけ小さくしても大丈夫です🙇‍♂️」

**遊びの手触り（速度・当たり判定・カメラ・音・ラウンド進行・言語）は1行も変えて
いません。** 変えたのは、5種類の台の大きさと、ワープの置き場所、そしてその大きさに
併せた「踏み判定・長押し距離」だけです。

## 1. なぜゴチャついていたか（実測）

ワープは1Fの角に2枚、階段パッドも同じ角に2枚ありました。

| 台 | Build 7 の中心 | 一番近い階段まで | 一番近い壁まで |
| --- | --- | --- | --- |
| ワープ（北東） | (300, -470) | **317px** | 15px |
| ワープ（南西） | (-300, 470) | **251px** | 15px |

南西は ワープ・階段・スイッチ候補・柱 が 250px 四方に集まり、北東も
ワープ・階段・スピード床・ゲート候補・柱 が重なっていました。台そのものは
すり抜けられますが、**踏みたい台の隣に別の台がある**ので、階段に乗るつもりが
ワープしたり、ワープの上で立ち止まって動きづらくなる、という状態です。

## 2. 置き場所（ワープの一対だけ移動）

角を離れ、**見通しの良い広い通路**へ移しました。位置は台の左上座標です。

| ワープ | Build 7 | Build 8 | 一番近い階段まで | 壁まで |
| --- | --- | --- | --- | --- |
| 北 | (245, -525) | **(120, -500)** | 317px → **444px** | 15px → **160px** |
| 南 | (-355, 415) | **(-180, 440)** | 251px → **398px** | 15px → **184px** |

- 一対の間隔は 1115px → **987px**。ワープの「遠くへ渡る」役割はそのままです。
- どちらも柱や壁から 160px 以上離したので、着地点（台の中心）に体が埋まりません。
- 階段・スピード床・スイッチ・ゲートの**位置は変えていません**（スイッチとゲートは
  ラウンドごとに10か所から抽選する仕組みもそのまま）。

## 3. 大きさ（5種類すべて 72〜76%）

| 台 | Build 7 | Build 8 | 比率 |
| --- | --- | --- | --- |
| ワープパッド | 110 | **84** | 76% |
| 階段パッド | 110 | **84** | 76% |
| スピード床 | 110 | **84** | 76% |
| 脱出ゲート | 96 | **72** | 75% |
| スイッチボタン | 84 | **64** | 76% |

見た目（3Dの板）と踏み判定は同じインスタンスの大きさから作られるので、両方が
一緒に小さくなります。厚み（Z）・色・テクスチャ・ラベルはそのままです。

## 4. 判定とAIの整合（ここが本題）

台を小さくしたぶん、**踏める距離・押せる距離・AIの止まる距離**を全部作り直しました。

| 判定 | Build 7 | Build 8 | 根拠 |
| --- | --- | --- | --- |
| スイッチの長押し範囲（プレイヤー） | 96 | **76** | 台の半径32 ＋ 体の半径8.5 ＋ 余白35 |
| スイッチの長押し範囲（CPU） | 34 | **28** | 64pxの台の上に立てる距離 |
| ゲートの接触判定 | 96（＋4） | **72（＋4）** | 台の実寸から直接 |
| ワープの踏み判定 | 110 | **84** | 台の実寸（マージン0） |
| スピード床の踏み判定 | 110（＋2） | **84（＋2）** | 台の実寸 |
| 階段の発動 | 中心が台の矩形内 | 同じ（84px） | v0.7.2 のAIは台の中心へ歩くので到達する |
| AIの階段降り位置（76pxステップオフ） | 76 | **76（変更不要）** | 84pxの台の半径42より外なので、降りた瞬間に再乗車しない |

`SWITCH_SIZE` / `GATE_SIZE` / `SWITCH_RANGE` は定数1か所で持っているので、
台の寸法と判定が食い違うことはありません。AIの長押し距離は新しい定数
`AI_SWITCH_HOLD_RANGE` にしました。

**確認したこと**：v0.7.2 の「AIは自分の階のパッドの中心へ歩く」経路、
v0.7.4 の壁認識ナビ（パッドの中心をゴールにする）、v0.7.0 のスイッチ意図
（スイッチ中心へ歩いて28pxで長押し）は、いずれも台の中心を目標にしているため
縮小の影響を受けません。着地・乗車・押下はすべて実測で通しています（§6）。

## 5. 追加した読み取り専用のシーン変数（テスト・調整用）
