# ICE WOLF v1.2.0 Build 38 — 1F/2Fの別フロア化・広大化・マスター鬼・接触凍結・OP・カメラ

Build 37 の実機試遊（05:54 の画面収録）と、そのあとの「演出がないと前ほどの楽しさがない」という
フィードバックへの対応。8つの改修要件と追加フィードバックをすべて入れました。

## 1. 日本語で起動する（英語で始まるバグの根本修正）

原因は2つありました。

1. `loadSettings()` が「保存された言語があるときは `i18n.init()` を呼ばない」作りだったこと。
   Build 35 の WKWebView が `en-US` と申告したときに保存された `language: "en"` が、
   以降の全起動でそのまま使われ、さらに `i18n.lang` が null のままなので全文言も英語に落ちていました。
2. デバイス判定が `navigator.languages` と `Asia/Tokyo` だけだったこと。

Build 38 の修正:

- `i18n.init()` は**必ず**呼ばれ、保存値は「設定画面で本人が選んだ言語」（`iceWolfLanguageChosen`）の
  ときだけ優先。それ以外は毎回デバイスに聞き直します（`navigator.languages` / `navigator.language` /
  `navigator.userLanguage` / `Intl…locale` / タイムゾーン）。
- `Info.plist` の `CFBundleDevelopmentRegion` を `ja` に（`CFBundleLocalizations` は12言語のまま）。
- `index.html` の静的ラベルも日本語（`stageLabel`）にし、JS 前の一瞬も英語が出ないようにしました。

## 2. 鬼は触れるだけで凍らせる

`isWolfForm(actor)` を追加し、**マスター鬼は常に true**、人狼鬼は変身中だけ true。
その状態の鬼は `WOLF.freezeRange`（1.15 → 1.3m）に入った人間をボタン操作なしで即凍結します。
クールダウン待ちはありません（人狼鬼の変身そのものが5秒の窓）。

## 3. マスター鬼はずっと鬼

- マスター鬼の `form` は `'wolf'` 固定。狼モードのタイマーもボタンもなし（HUD から `[人狼]` を外し、
  `[指名]` は試合中いつでも押せます）。
- 見た目も常に角とマント（`actor.form === 'wolf'` で描画）。
- ヒントは「マスター鬼はずっと鬼。触れるだけで人間を凍らせる」、人狼鬼は従来どおり
  「変身」で人間⇔鬼。遊び方（`how.p2`）も12言語ぶん書き直しました。

## 4. ステージ構造：1Fと2Fを別フロアに分離・広大化

- **積み重ねをやめました**。1ステージの中に西の1Fホール（48×40m）と東の2Fホール（48×40m）が
  並び、間は8mの虚空と高さ8mの氷の尾根で仕切られます。2Fの床が1Fを隠す問題は構造的に消えました。
- 各フロアは 1,920m²（旧アリーナ全体 1,728m² より広い）。`stage.floors[1] / [2]` の矩形から
  外周壁と2階層ナビを自動生成します（`core/geometry.js`）。
- **階段ゾーン**：木のゲート＋3段の飾り階段＋リング。乗るだけで別フロアの着地（2.6m 内側）へ。
  立体の傾斜はありません。
- **ワープゾーン**：同じフロアの離れた2地点（マゼンタの渦）。フロアは変わりません。
- 階段とワープは**同じフロア上で12m以上**離すことを `tools/audit-stages.mjs` とユニットテストが強制。
- 6ステージそれぞれに、両ホールの内壁レイアウト・スイッチ13候補（1F 7 / 2F 6）・ゲート3・
  パッド4・階段2対・ワープ2対を配置し直しました。

## 5. スイッチの文字表記

スイッチの上に「スイッチ／SWITCH」の浮遊サイン。同じ仕組みで
「階段 2Fへ」「ワープ」「1Fフロア／2Fフロア」も表示し、言語を変えると
`view.refreshLabels()` が全サインを描き直します（12言語）。

## 6. カメラ（DOROKEI 方式）

- 内壁は **1.25m**（キャラクターの目線より低い）に。そもそも体を隠しません。
- 外周壁は **2.8m**、観覧車・テント・かまど・船体・氷の尾根・閉じた教室シャッターは
  **カメラとプレイヤーの間に立つと半透明**（`updateOcclusion`）。高い障害物のそばでは
  カメラが少し持ち上がります（`camLift`）。
- 追従カメラはやや寄り・高め（高さ11.8m / 距離9.2m）にし、進行方向へ1.1m 先読みします。

## 7. オープニング

- **3.2秒**のタイトルシーケンス。壁時計で動くので、フレームレートが低い端末でも短くなりません
  （Build 37 は加算 dt だったため、実機で一瞬に見えていました）。
- 吹雪の中、マスター鬼が人間を追い、1.75秒で1人を凍らせ、カメラが引いてロゴが落ちる構成。
  追跡路はステージごとに「壁の無い最長の一直線」を実行時に探すので、壁を突き抜けません。
- 画面のどこをタップしてもスキップ。起動のたびに再生します。
- ロゴ・タグライン・霜・斜めの吹雪・爪痕は CSS（`styles.css` の `.op-*`）、世界観は3D側で表現。

## 追加フィードバック（演出・教室・壁の高さ）

- **廃校の教室閉じ込め**を復活。チャイム2.5秒（鐘が揺れ、警告音と画面表示）→
  シャッターが実際に降りて（3.2m、アニメーション）、**当たり判定も閉じます**（ドア帯に入った体は
  押し出され、通れない）。閉まっている間はHUDのヒントにも残り秒数が出ます。
- **classic**：18秒ごとに4.5秒の吹雪の突風（氷が流される）＋オーロラ＋氷柱＋地面の霧。
- **aquarium**：マンタに加えて魚群（16匹が2つのホールを回遊）、水中の光の筋、泡。
- **park**：観覧車が回り、メリーゴーラウンドが回り、パレード中は山車が動いて紙吹雪が降る。
- **lodge**：吹雪の壁＋ランタン8灯と暖色のポイントライト2つ。
- **space**：SFゲート（重力発生で赤く脈動）、浮遊する隕石、低重力/高重力の実効果（速度1.18倍 / 0.55倍）。
- どのギミックも開始時にトースト表示＋効果音（`announceGimmick`）。教室は専用の「ドア」音を追加。
