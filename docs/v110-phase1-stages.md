## 2. ステージはどう切り替わるか

**同じアリーナ、同じ境界。** 外周の壁8枚・床2枚・バリア4枚は全ステージ共通で、
動くのは**内側の壁52枚**だけです。だから

- 遊べる範囲（1F: x −708…692 / 2F: 892…2292、y ±708/692）は変わりません。
- 2階の判定（中心 x が 792 より右なら 2F）も変わりません。
- AI のナビゲーション（16px グリッド、1F/2F の帯）も同じ枠で組み直せます。

壁は**サイズを変えず、位置だけ**動かします（`setX` / `setY` のみ）。1.0.0 の
当たり判定・テクスチャ・3Dの箱は、壁ごとに決まった寸法のままです。各ステージは
「160×32 の壁はここ、90×90 の柱はここ…」という**寸法ごとの置き場所**で書かれて
います（`game.json` の `ICE_WOLF_STAGE_WALLS`）。使わない寸法の壁は、アリーナの
外（x −2600 / y 40000）に待避します。

切り替えの手順（`v1.1.0 ステージ・衣装` ブロック）:

1. 内側の壁52枚を、選んだステージの位置へ移す
2. 床と壁を、ステージの色で染める（`floor_frostlab.png` のテクスチャはそのまま。
   色を掛けるだけなので、氷の質感は残ります）
3. ナビゲーショングリッドを捨てて、次のフレームで新しい壁から組み直す
4. `V070ResetPending` を立てて、スイッチ5個とゲート3個を新しい床から配り直す
   （壁に埋まった台が出ないように）
5. 大気（DOM の固定オーバーレイ、`pointer-events:none`）と衣装を切り替える
6. 遊んでいる最中は壁を動かしません（メニュー／役割発表／カウントダウンだけ）

## 4. 10人戦・2人狼・カスタムルール

| 設定 | 無料 | PRO | 備考 |
| --- | --- | --- | --- |
| プレイ人数 | 7 / 8 / 9人 | **10人** | シーンに CPU を9体用意（A〜I）。入らない分は `State = "Out"` で待避 |
| 人狼の数 | 1人 | **2人** | 2人狼は8人以上の試合だけ |
| スイッチの数 | 5個（1.0.0 と同じ） | **3個 / 4個** | 正解はいつも3個。ダミー／罠の数が変わる |
| 試合時間 | 2 / 3 / 5分 | **1分 / 10分** | 未設定なら 3:30（1.0.0 のまま） |

- 設定は既存の **SETTINGS** に3行（プレイ人数・人狼の数・スイッチの数）と、
  試合時間の行に2つのチップ（1分・10分）を足したものです。
- 反映は**次の試合から**（1.0.0 の試合時間設定と同じ扱い）。試合中に人が増減しません。
- 無料のまま10人を選ぶと9人に、2人狼を選ぶと1人狼に丸めます。UI では押した瞬間に
  Pro 画面が開きます。
- 「Out」の CPU は、生存数・凍結数・勝敗・IDラベル・3Dの見た目から外れます。
  つまり**7人戦は1.0.0と完全に同じ数字**（生存6・凍結0で始まる）です。

## 5. 観戦カメラ

人間が凍結されると、その試合は最大5分まだ続きます。これまでは氷の塊を映したまま
でしたが、**生存中の CPU（人間も人狼も）を前/次で切り替えて追える**ようにしました。

- 画面下中央に `‹ 観戦中: C ›` のバー（凍結中だけ表示、52px のボタン2つ）。
- 追従先は `SpectatorFocus = "1"` を付けた Actor 1体だけ。カメラは GDevelop の
  `ThirdPersonCamera` を **Actor** に対して、1.0.0 と同じ距離（600/53、俯瞰は1050/78）
  で動かします。既存のカメラグループは `SpectatorActive = False` のときだけ動くので、
  2つのカメラが取り合いません。
- 解凍・救助・試合終了の瞬間に、バーが消えてカメラが自分に戻ります。
- 位置・役割・状態・タイマーには一切書き込みません（焦点マーカーだけ）。
