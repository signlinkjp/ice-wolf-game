# ICE WOLF v0.7.3 — ブロックトイ風3Dキャラ（案3）

v0.7.3 は、トモアキさんが選んだ **案3「ブロックトイ風（カクカク立体）」** を、
プレイヤーと6人のCPUの全員に着せた回です。デザイン基準は `downloads/iw-char-style-3.png`
（明るいシアンのヘルメット＋白いゴーグル、白×シアンのジャケット、茶色のベルトと
バックパック、茶色のブーツ／チャコールの狼・赤黒の尖った耳・赤い目・白いマズル・爪）。
ゲームの当たり判定・凍結・AI・UI・SETTINGS・HOW TO PLAY には一切触れていません。

## 1. 人間（通常時／潜伏中の人狼も同じ見た目）

v0.6.8 の「頭＋バイザー＋キャップ」6パーツを、**30ブロックのミニフィグ調**に置き換えました。

| 部位 | ブロック |
| --- | --- |
| 脚・ブーツ | 白い脚2本、前に少し張り出す茶色のブーツ2つ |
| 胴 | 白いジャケット、シアンの胸パネル、茶色ベルト＋金属バックル |
| 腕 | 白い腕2本、シアンの肩当て2つ、茶色のグローブ2つ |
| 頭 | 肌色の首＋頭（12.4×13.6×12.4） |
| ヘルメット | シアンの天板・後頭部・耳当て2つ |
| ゴーグル | 白い枠（上下左右の4本）＋枠の奥に引っ込んだシアンのレンズ |
| 顔 | **8角形の円盤**の黒い丸目2つ＋小さな笑顔（茶色の口） |
| 背中 | 茶色のバックパック＋上の丸めた荷物 |

- 目は Box ではなく **8角柱（CylinderGeometry 8分割）を +X に向けて** 結合しており、
  「丸い目」に見えます。口は小さな箱です。
- 正面は **+X**（GDevelop が Player の `SetAngle(ToDeg(atan2(MoveY, MoveX)))` で回す軸）。
  そのため歩いた方向に顔が向きます。CPUは object の angle を触らず、
  **rig の body だけを歩いた方向へ回す**ので、CPUも自然に前を向いて歩きます
  （転移（階段ワープ1600px）では回転しません。凍結中も回しません）。

## 2. 人狼（`WolfModeLeft > 0` / `AIWolfModeLeft > 0` のときだけ）

**31ブロック**のチャコールの狼に差し替わります。

- ずんぐりした黒い体・長い腕・爪のある前足／後ろ足（赤茶の爪）
- 白いマズル＋黒い鼻、赤い口の中に牙2本
- **赤く光る目**（幅4.2の横長）＋怒り眉
- **赤黒の尖った耳**：太い根元→細い先端の2段積みで「尖り」を出し、内側は赤
- 人間のジャケットの名残として**シアンのベスト**パネルと茶色ベルト

### 正体隠匿（v0.6.10 の不変条件を維持）

| 状態 | 見た目 |
| --- | --- |
| 人間 | 人間ブロックトイ |
| 人狼・潜伏中（`WolfModeLeft` / `AIWolfModeLeft` が 0） | **人間ブロックトイ**（赤い耳は出ません） |
| 人狼・WOLF MODE 中 | チャコールの狼 |
| 凍結（`Frozen` / `FrozenWolfCandidate`） | 人間ブロックトイ＋氷ブロック（狼だったことは分かりません） |

WOLF MODE が切れた時・ラウンドリセット時は、そのフレームで必ず人間ブロックトイに戻ります。

## 3. 軽さ（iPhoneで重くしない）

- 体は **1つの結合メッシュ（Box 30個／狼31個 → position/normal/color の1ジオメトリ）**。
  色は頂点カラーに焼き込むので、マテリアルは**全キャラ共有の1個**だけです。
- ジオメトリは「人間」「狼」の**2つだけ**を作ってシーンにキャッシュ。WOLF MODE の
  入り切りは `mesh.geometry` の差し替えだけで、**フレームごとのメッシュ生成や再結合はゼロ**。
- 1キャラあたりのメッシュは **体1＋氷1＝2個**（7人で14個。v0.6.8は42個）。
- 影は結合メッシュ側で落とし、元の立方体は影も消しています。

## 4. 失敗しても壊れない

- 3Dレンダラが無い／壊れている場合は結合メッシュを作らず、**従来の単色キューブ**
  （v0.3.4 の白／人狼は暗赤／凍結は氷色）がそのまま残ります。
- rig の組み立て中に例外が出た場合も、立方体の元の6面マテリアルを**書き戻して**
  体メッシュを隠すので、透明人間にはなりません。

| 変数 | 意味 |
| --- | --- |
